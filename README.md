## Featured Work

### FleetPulse — Industrial Predictive Maintenance Platform

> Private source repository · production-oriented portfolio project

An end-to-end equipment intelligence platform that receives industrial sensor
telemetry, estimates health and remaining useful life, escalates maintenance
alerts, and presents fleet status through an operational dashboard.

- FastAPI, SQLAlchemy, PostgreSQL, and role-based authentication
- Bounded telemetry ingestion with model-backed health scoring
- Deduplicated warning-to-critical alert lifecycle and maintenance records
- Structured logs, correlation IDs, health probes, and Prometheus metrics
- Docker, GitHub Actions, and validated AWS ECS Fargate infrastructure
- 11 automated tests with 91% statement coverage
